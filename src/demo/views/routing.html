Routing

Routing is defined via the æ.router class. You create an instance of it and set the URLs and the routings for these URLs, i.e., how the web application should handle the URL.

  var router = æ.router();
  var v = æ.view('#view');

  router.on('/', function () {
    v.show('views/fragment0.html');
  });

Route Parameters

Parameters get prefixed with a colon, e.g., :id for a parameter that should be named id.

  router.on('/myobjects/:id', function () {
    v.show('views/fragment0.html');
  });
